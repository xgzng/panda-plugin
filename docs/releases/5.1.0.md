# Panda 5.1.0

Panda 本次从基于 Ponytail 4.9.0 的实现，适配到稳定标签
[Ponytail v5.3.3](https://github.com/DietrichGebert/ponytail/releases/tag/v5.3.3)
（`7801d061243d7b753bad0e0b3c057cd250b11755`）。Panda 独立发布，不是 Ponytail 官方版本。

## 继承与增强

- 新版最小完整实现规则：编码前确认调用方、测试、配置、导出与数据影响；复用项目现有组件；交付完整需求，避免只追求短 Diff。主 Skill 继续使用中文。
- Review/Audit 从“只找可删代码”扩展为正确性、安全、真实负载、必要测试、性能、复杂度和无关改动审查。每条发现提供位置、场景、最小修复与后果；不擅自修改代码或切换模式。
- 模式修复：Codex 切模式时立即提供新规则；上下文压缩保留当前模式；不同项目的状态用哈希键隔离；Qoder 支持自定义配置目录，关闭与默认模式不再混淆。单次 Review 不再锁成持续模式。
- 更稳的生命周期 Hooks：安全启动、同步输出、stdin 超时恢复和有限时长的代码地图。地图是辅助索引，不能替代读取项目规则和源代码。
- Cursor Hooks、OpenCode V1/V2 与压缩恢复、Pi/OMP 会话切换与缓存保留、Hermes 避免逐轮重复注入；新增 Kimi 清单并补齐 Grok marketplace 契约。
- Claude Code Band/Board：查看任务成本、Token、Agent 时间、启发式复用和测试状态；支持 `/panda band`、`/panda band on|off`、`/panda band import`。
- 新简化标记为 `shortcut:`，继续识别历史 `panda:` 和 `ponytail:`。Debt 扫描遵守 `.gitignore`，包含块注释。
- 更新中英文 README、帮助卡、命令分发和 OpenClaw 副本；同步 Ponytail 5 的公开基准说明，但不把它作为 Panda 收益。

公司安全与质量底线、编码前项目规则入口检查、规则优先级和 Surgical Changes 均保留。
它们是 Agent 约束和自检机制，不是代码级强制隔离。

## 看板范围和数据

看板仅支持 Claude Code 2.1.290+ 的终端和桌面 Code 会话，不支持 Codex、VS Code 聊天、云会话和 `claude -p`。测试使用 Claude Code 2.1.311 的官方插件模拟框架，不调用模型。

默认指标和任务名只留在本机 Panda 配置目录的 `band/`，不设置 webhook；外发任务名默认关闭。设置 HTTPS webhook 后才外发。`ledger=false` 停止后续行写入；隐藏看板不会关闭本地记账。

历史导入可能按上游固定的 2026-10-17 费率估算，不等于真实账单；未知历史成本保留为空，不计为零。复用计数是部分语言的启发式统计，不支持 Java，不代表 TBS 的真实复用率。证明节省仍需同需求、同模型和相同环境的基线对照。

## 兼容与限制

- 保留 Panda 配置目录、`PANDA_*` 优先级、旧 `PONYTAIL_*` 兼容变量和内部 `ponytail-*` 文件名。
- 新会话使用配置的默认模式；上下文压缩保留实时模式。不同项目的规则状态隔离；同一项目并发会话仍共享实时模式。
- 兼容状态栏与看板的模式标签读取共享状态，不同项目并行时标签可能显示最近一次切换的模式；实际注入规则按项目状态执行。
- Cursor 的 always-on 规则文件无法由命令关闭。想改用 Hooks 管模式，先由用户移除对应 Panda 规则；安装器不会主动删除它。
- 不复制上游营销图片、赞助和 npm 发布工作流，不新增 npm 发布、付费模型调用或全局用户配置。
- 不重跑历史 Leads 对照实验；本次兼容测试不能证明收益百分比或所有生产安全场景。

## 更新

Codex CLI（Windows 可使用 `codex.cmd`）：

```bash
codex plugin marketplace upgrade panda
codex plugin remove panda
codex plugin add panda@panda
```

完成后重启 Codex 客户端或新建 CLI 会话，并检查新 Hook 的信任状态。Claude Code 使用 `/plugin marketplace update panda`、`/plugin update panda@panda`，然后按提示 `/reload-plugins`。

回退时应重新安装旧版本插件包；不要将上游 Ponytail 标签当作 Panda 标签。本次不创建 Git tag。

- Windows：根目录 Node 测试 156/156、Pi 31/31、MCP 3/3。
- Claude Code 2.1.311 官方插件测试框架：Band/Board 38/38，包含 webhook 任务名缺省、关闭、显式开启三种行为，均使用模拟网络。
- 规则副本、八处版本一致性、Diff 检查和全新隔离 Codex 本地安装通过。安装后校验 5.1.0 清单，以及 lite/full/ultra 的公司规则与 Surgical Changes、off 的空注入。

## English release note

Panda 5.1.0 adapts stable Ponytail v5.3.3, retaining the Chinese main Skill,
company safety/quality baseline, project-rule discovery and Surgical Changes.
It updates full-scope implementation guidance, quality review/audit, lifecycle
state and compaction handling, Cursor/OpenCode/Pi/Hermes adapters, and the
Claude-only local task band/board. Upstream benchmarks remain attributed to
Ponytail; no new Panda savings experiment was run. See the bilingual README
for configuration, supported hosts, measurement limits and update commands.
