Show the panda quick reference. One shot, change nothing: do not switch mode, write flag files, or persist anything. Levels: /panda lite (build what's asked, name the lazier alternative in one line), /panda (full, the default ladder: YAGNI then stdlib then native then one line then minimum), /panda ultra (deletion before addition, challenges the requirement before building). Commands: /panda-review (over-engineering review of the current changes), /panda-audit (whole-repo over-engineering audit), /panda-debt (harvest panda: comments into a tracked ledger), /panda-gain (measured-impact scoreboard from the benchmark), /panda-help (this card). Deactivate with 'stop panda', 'normal mode', or /panda off; resume anytime with /panda. Default mode is full; change it with the PANDA_DEFAULT_MODE environment variable (off|lite|full|ultra) or a config file at ~/.config/panda/config.json (Windows: %APPDATA%\panda\config.json) with {"defaultMode": "lite"}. Resolution order: env var, then config file, then full.
